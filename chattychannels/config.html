Plugins / ChattyChannels

Configuration reference

This is the config.yml ChattyChannels writes on first start, comments included. Every key you see here is the key the plugin reads; there are no hidden ones. Change a value, reload, and it applies.

Top-level sections: language, server-name, mysql, chat, logging, friends, rank-preview, config-version.

﻿# ChattyChannels configuration
# Main plugin settings are in channels.yml

# Active language. ISO-639-1 two-letter code (lowercase).
# Bundled out of the box: es (Spanish), en (English).
language: en

# Unique name for this server instance. Shown in /friend list when MySQL is active.
server-name: "survival"

# MySQL connection. Set enabled: true and fill credentials to unlock cross-server features.
mysql:
  enabled: false
  host: "localhost"
  port: 3306
  database: "chatchannels"
  username: "root"
  password: ""
  pool-size: 5

# Chat line. Other chat plugins (LPC, EssentialsX Chat...) redraw the line after ChattyChannels and drop the
# channel tag. With draw-line-last ChattyChannels draws its own line once more at the end. Rank prefixes come from
# %luckperms_prefix% in channels.yml, & and § colour codes included, so LPC is not needed for them.
chat:
  draw-line-last: true

# Chat logging. Writes a daily-rotated log to plugins/ChattyChannels/logs/chat-YYYY-MM-DD.log
logging:
  enabled: true

# Friends system settings.
friends:
  max-friends: 50
  request-ttl-days: 7
  notify-on-join: true

# Rank preview: now and then a private chat line shows the player's name with the NEXT rank of this server
# (price in the server currency with an optional real-money equivalent, click opens the shop). Off by default; /avisos rangos off turns it off per player.
# Example table; set url (shop link, empty = no link), hook and ranks for your own server.
rank-preview:
  enabled: false
  first-delay-minutes: 10        # never in the first minutes after joining
  interval-minutes: 30           # between two lines for the same player
  pause-after-purchase-days: 7   # silence after the player buys a rank
  exempt-permission: chatchannels.rankpreview.exempt   # staff never gets it
  combat-placeholder: "%combatlogger_in_combat%"       # PlaceholderAPI value "true" = in combat, nothing is sent
  url: ""                        # shop link shown under the line; empty = no link
  hook: "plus more perks"        # one short phrase after the preview
  ranks:
    - { group: box_vip, name: "VIP", color: "#6FCF7E", price: 500, eur: "4,99 €" }
    - { group: box_pro, name: "Pro", color: "#4FC3F7", price: 1100, eur: "9,99 €" }
    - { group: box_mvp, name: "MVP", color: "#F2C14E", price: 2400, eur: "19,99 €" }
    - { group: box_elite, name: "Elite", color: "#FF8A3D", price: 3500, eur: "29,98 €" }
    - { group: box_immortal, name: "Immortal", color: "#E0533D", price: 6500, eur: "49,99 €" }

config-version: 3
