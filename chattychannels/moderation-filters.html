Plugins / ChattyChannels

Moderation filters

New in 1.5.0. They live under filters in channels.yml and reload with /cc reload. They run on channel chat and on private messages (/msg, /r).

Key Default Effect
blocked-words [] Always blocked, whatever words.mode says. For slurs and threats
watch-words [] Delivered as normal, but written to the flag log for staff to review
advertising.enabled true Blocks server IPs and web addresses
advertising.block-ips / block-domains true Which of the two to look for
advertising.allowed-domains YouTube, Twitch, Imgur Your own domain and anything players may share; subdomains are included
auto-mute.enabled true Mutes in every channel after repeated blocked messages
auto-mute.strikes / window-minutes / minutes 3 / 10 / 15 3 blocked messages within 10 min 15 min mute
flag-log.enabled true One JSON line per blocked or watched message in logs/flagged.jsonl
flag-log.include-spam false Also log duplicate, caps and flood hits

Every word list (words.list, blocked-words, watch-words) also catches the usual dodges: accents, 0 4 3 1 5 7 @ $ for letters, repeated letters (puuuto) and letters split by spaces or dots (p u t o). A dodged word can't be masked in place, so that message is blocked.

IP and address detection understands play.server.net, 123.45.67.89, server (dot) net and server [punto] net. Coordinates and version numbers (1.21.4) are not mistaken for an IP. Two-letter endings that are also everyday words (.es, .me, .co…) only count with a subdomain (mc.server.es), so a sentence like eso.es passes.

Flag log line:

{"ts":"2026-10-11T04:40:00Z","server":"survival","player":"Steve","uuid":"…","channel":"global","kind":"blocked-word","match":"slur","message":"…"}

kind is one of blocked-word, ad, word, watch-word, auto-mute or spam-<reason>. channel is pm:<target> for private messages.

A player muted in every channel (/mute <player> * or the automatic mute) can't send private messages until the mute ends. Players with chatchannels.bypass.filter skip every filter. Messages: filter-word-block, filter-ad-block, filter-auto-muted.

filters:
  blocked-words: ["slur1", "threat phrase"]
  watch-words: ["how old are you"]
  advertising:
    enabled: true
    block-ips: true
    block-domains: true
    allowed-domains: ["myserver.net", "youtube.com"]
  auto-mute:
    enabled: true
    strikes: 3
    window-minutes: 10
    minutes: 15
  flag-log:
    enabled: true
    include-spam: false
