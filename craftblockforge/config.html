Plugins / CraftBlockForge

Configuration reference

This is the config.yml CraftBlockForge writes on first start, comments included. Every key you see here is the key the plugin reads; there are no hidden ones. Change a value, reload, and it applies.

Top-level sections: settings, stations, message, worlds, regions.

# CraftBlockForge — config.yml
# Item names are Bukkit material names (DIAMOND_SWORD, TNT...).
# Wildcards work in every list: * = any text, ? = one character (e.g. "*_SWORD", "NETHERITE_*").
# Items from other plugins go by their id with a prefix: "itemsadder:myitems:ruby", "oraxen:ruby_sword",
# "nexo:ruby_sword", "executableitems:ruby", "mmoitems:SWORD:RUBY", or "pdc:<namespace:key>=<value>" for any
# plugin that tags its items. "/craftblock block hand" adds the item you hold, by its id when it has one.
# A material entry (DIAMOND_SWORD) also covers custom items made from that material.

settings:
  # blacklist = block the listed items | whitelist = block everything except the listed items
  mode: blacklist
  enabled: true
  # en or es
  locale: en
  # Tell players with craftblockforge.notify when someone tries to craft a blocked item
  notify-admins: false
  # Write every blocked attempt to the console
  log-attempts: false
  update-checker: true
  # Minutes between stats saves
  stats-autosave-interval: 5
  # What the result slot shows for a blocked recipe before the player clicks:
  # barrier = a barrier named "Blocked" | hide = an empty slot | off = the real item (blocked on click)
  preview: barrier

# Other stations that follow the same lists, worlds and regions.
stations:
  smithing: true
  stonecutter: true
  # Furnaces, smokers and blast furnaces. Nobody stands at them, so only the world lists and the global mode apply.
  furnaces: false
  # The anvil: a blocked item can't be renamed, repaired or combined there.
  anvil: false

message:
  enabled: true
  # Leave empty to use the text from messages_<locale>.yml. &-codes and MiniMessage (<#ff5555>, <gradient:red:gold>) both work. Placeholders: {item} {player} {world} {region}
  text: ""
  # CHAT, ACTIONBAR or TITLE
  type: CHAT
  sound: ENTITY_VILLAGER_NO
  # Seconds before the same player sees the message again
  cooldown: 3

# One section per world. "default" is used by every world without its own section.
worlds:
  default:
    enabled: true
    mode: blacklist
    blocked:
      - DIAMOND_SWORD
    allowed: []
    custom-messages: {}
#  world_nether:
#    mode: blacklist
#    blocked:
#      - "*_BED"
#    custom-messages:
#      RED_BED: "&cBeds explode in the Nether!"

# Lists for WorldGuard regions (needs WorldGuard). The key is the region id.
# The region flags deny-craft, deny-craft-items and allow-craft-items are checked first.
regions: {}
